# 🌻 Flores Amarillas — Para ti

Página web romántica dedicada a una persona especial, creada con **HTML, CSS y JavaScript** en un único archivo principal.

## ✨ Experiencia de la página

La página está diseñada como una experiencia paso a paso:

1. Primera frase romántica sobre el significado de las flores amarillas.
2. Botón **Continuar →** para avanzar.
3. Segunda frase dedicada.
4. Nueva transición con botón **Continuar →**.
5. Pantalla previa al ramo con el botón **Ver tus flores 🌻**.
6. Aparición del ramo de flores amarillas con animaciones.
7. Botón para continuar hacia **Nuestros recuerdos**.
8. Galería de fotos con carrusel y visualización ampliada.

## 🌻 Características

- Diseño romántico, elegante y moderno.
- Estilo visual oscuro con detalles amarillos.
- Flores amarillas animadas.
- Pétalos cayendo.
- Corazones flotando.
- Luces y partículas de fondo.
- Transiciones suaves entre pantallas.
- Botones para avanzar paso a paso.
- Galería de recuerdos.
- Carrusel automático y manual.
- Compatible con teléfonos y computadoras.
- Sin frameworks ni librerías externas.
- Todo el contenido funciona desde un único `index.html`.

## 📁 Archivos

```text
floresamarillas/
├── index.html
└── README.md
```

- `index.html`: contiene la página completa, animaciones, estilos, JavaScript y fotografías incrustadas.
- `README.md`: descripción e instrucciones del proyecto.

## 🚀 Publicar en GitHub Pages

1. Sube `index.html` y `README.md` a la raíz del repositorio.
2. En GitHub entra en **Settings**.
3. Selecciona **Pages**.
4. En **Build and deployment** configura:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main`
   - **Folder:** `/ (root)`
5. Pulsa **Save**.
6. Espera unos minutos a que GitHub publique la página.

El enlace tendrá un formato similar a:

```text
https://TU-USUARIO.github.io/floresamarillas/
```
